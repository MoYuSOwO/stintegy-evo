# StintegyEVO simulation core

This directory contains the strategy-first simulation core imported from the
local `the-stint` prototype at commit `f5b33eab7967bbd0a8a3c2d591c0dbcf24d0d669`.

`StintegyEVO.Core` is the internal simulation namespace. The prototype remains
part of the repository history, while the product, repository, logo, and public
brand use **StintegyEVO** consistently.

The previous high-fidelity vehicle and controller implementation is preserved
in Git history before the `reboot/the-stint` branch point; it is intentionally
not compiled alongside this core.
