# 能力与性格：一个母本如何开出一整张格子

记录日期：2026-09-12。用户质疑：能力值系统本质上共用一个 checkpoint，
真跑起比赛会不会毫无性格差异？答案：纯噪声确实造不出性格——
噪声零均值，只改失误率。性格需要偏置。四层公式：

## 方差定能力，偏置定性格，指令定风格，血统定流派

1. **方差（能力值）**：接口失真的幅度。零均值噪声/量化/延迟 →
   失误率与稳定性档位。原则照旧：失真留在训练分布内（她救得回来）。
2. **偏置（性格）**：接口失真的方向。系统性偏移 = 肉眼可见的人格：
   - 抓地感知偏乐观 → 晚刹车、弯心带滑（激进派；刹车点最可见）；
   - 胎温偏乐观 → 冷胎敢推；偏悲观 → 暖胎仔细、雨天老江湖；
   - 对手距离偏乐观（对决代）→ divebomber；偏悲观 → 让线；
   - **条件方差**：噪声随情境缩放——缠斗手抖=压力崩盘型，
     雨天方差不变=雨神。压力人格全在此层。
3. **指令（风格）**：对手 pit wall 也是模拟的一部分，各队的档位/预算
   使用风格（全场高推 vs 精算养胎）经真实的档位响应面产生真实
   不同的驾驶与线路。策略游戏的对手在策略层有性格——主题自洽。
4. **血统（流派）——训练室专用，不上货架**（2026-09-12 用户裁决降级）：
   素材库的真不同策略（流浪段野线怪、650k 稳健派）只作对决代
   **陪练池**的磨刀石；风格炉若做，是现役世代的兄弟（随母本赶
   代际班车），不是化石。不发货的三个理由：检查点随世界变更成批
   过期（人格若是权重，每次班车重烤全员）；老检查点失败无界而
   丑陋（打转看着像坏了，而①②层失真有界、锁在可救回包络内）；
   包内每人 28MB 的版本噩梦。

**发货结构：一份现役检查点 + N 份人格档案**（偏置向量、噪声幅度、
指令风格，数百字节，落在 DriverProfile）。核心性质：**人格是数据，
数据不过期**——世界变更后重烤一炉母本，全体车手自动换代，因为
他们从来不是权重，只是戴在权重上的眼镜和手套。

## 攻防数值（用户裁决必备，2026-09-12）

racecraft 数值 = 眼镜戴到对手块（6 席 × 16 通道）上，无需新机制：

- **进攻值** = 对前方空隙的乐观度（前车距离/靠近速度偏乐观 →
  敢扎晚出手；偏悲观 → 教科书超车手）；
- **防守值** = 对身后威胁的敏感度（后车报近 → 提前占线关门勤；
  报远 → 门户洞开、好超）；
- **缠斗沉着** = 交通中的条件方差（近身噪声放大倍率）；
- **战斗资源风格**（第③层）= 为超车烧电烧胎的意愿。

前提锁死：**数值调节能力，不能无中生有**——须先由对决代联赛
+赛例裁判把真实攻防本事炼进母本，数值才有东西可调。标定同
能力值：场景切片批量测，进攻 90 vs 70 须兑现为可测量的超车
成功率差。

## 反射层随机化（用户预警，2026-09-14，世界封版前置项）

反射层（#56）上车后的新盲区：从零原住民若只在完美反射层下长大，
"越顶后滑动"一族状态将从其训练分布中消失——软垫房童年，救车
本事失传；花名册时代降级反射层精度的人格会把它推进救不回的
状态（240 秒盲区的第三次轮回，出生前拦截）。裁决：

1. **反射层质量进随机化课程**（完美↔松弛↔偶尔关闭，逐回合抽），
   保住失控状态族的分布覆盖与救车技能；
2. **藏着不喂**（不进描述块）：反射层质量是能力不是设定，按
   "能力欺骗接口"处理。副产品的通用余量是真实的；藏着才保住
   花名册的真实失误率差异；
3. 老 TC/ABS 常数（TractionControlStrength 等，CarConfig init 面）：
   排期取决于虚构裁决（悬案）——A 路（F1.5 守禁令）删除/归零，
   随机化问题消灭，主脑倾向此路（反射层已覆盖其职责，留着是
   重复建设）；B 路（保留为可调装备）则它们是设定非能力，
   随配方时代箱体班车**随机化+喂描述块**。条件项：虚构裁决
   若走 B 路，其随机化升级为世界封版前置（"会变的必须先变过"）。
时序：冠军认证不受影响（其救车履历来自狂野年代）；本条卡在
从零原住民点火之前，列入世界封版检查单。

诚实边界：偏置层人格共享同一驾校的基本功，极端场景露同源痕迹；
长期由联赛代际的自然分化（训练室内）缓解。与"能力欺骗接口，
设定告知网络，战略命令网络"三联相容。
