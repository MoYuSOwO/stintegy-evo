# 顶层设计 v2：从"考试机器"回到"游戏"

记录日期：2026-09-14。起因：用户指出项目有"为了单圈而训练"的漂移，
且 GPU 机时收费在即，要求先细想清楚：能力值、进站、攻防、训练架构，
逐个压力测试而非乐观陈述。本文是裁决底稿。

## 一、过往轨迹的诚实总账

| 阶段 | 名义目标 | 真正买到的游戏资产 | 漂移成分 |
|---|---|---|---|
| 换心手术 | 真实极限手感 | 物理可信度（玩家体验的地基） | 无 |
| 稀缺/热力/随机化 | 世界定型 | 能量策略维度、包络教义、跨赛道泛化 | 无 |
| 化石清剿+记分牌 | 治病 | 物理与测量的健康 | 无 |
| 熵税/定型段 | 收敛 | 谷底α配方（生产工艺） | 尾段开始追纪录 |
| 铰链+反射层 | 零旋转 | **档位强制执行（玩家指挥接口的地基）**、能力系统基座 | 立法动机是考试指标 |
| 最后两轮 | 磨最后一跤 | 递减 | **主要成分** |

判词：基建收获是真实且巨大的，但最近的优化目标——"飞驰卷面上
的最后一跤"——是**我们自己发明的考试**，而游戏里不存在这门考试：
游戏车手在玩家档位指挥下跑管理配速，从不连续 600 秒全推。

## 二、考试与游戏的错位（本文最重要的一条）

现行毕业判据全部定义在"3/3 连续飞驰"上。游戏真正需要的是：
1. **指挥精度**——玩家命令的档位/配速被精确执行（产品核心）；
2. **比赛配速下的稳定性**——管理节奏下的旋转率（而非全推下的）；
3. **包络鲁棒**——旧胎、亏电、低抓地下不崩；
4. 配速只需"可信地快"（正赛带已超纲 4 秒，早已满足）。

**一个便宜测量可以重排全部优先级**：5×5 档位矩阵（PR 乙工具）
读出各档位的旋转率。若旋转只活在 4/4、5/5 攻击区、比赛档位
(≤3/3)本就干净——则"最后一跤"是纯考试现象,零旋转战役就地
终战,耐心臂降级为免费背景任务,GPU 与注意力转向真正未验证的
系统。此测量先于一切 GPU 支出。

## 三、能力值系统压力测试（用户点名细挖）

架构（方差=能力、偏置=性格、指令=风格）的**最弱一块砖是
"偏置→性格"假设**，两个真实风险：

1. **反馈冲刷**：她是闭环驾驶员——抓地通道被谎报 +2%，但每一帧
   的已实现滑移、实际轨迹都在报真相。策略可能靠真实反馈把谎言
   大部分修正掉，产出的不是"激进性格"而是"轻微变糟"；
2. **离流形风险**：训练中各通道彼此一致（都报真值）；被偏置的
   通道与其余通道**系统性矛盾**是训练分布外的输入组合——产出
   可能不是连贯性格而是不可预测的怪行为。

**裁决：偏置假设在花名册设计前必须实证。** 偏置探针实验（纯评估，
数小时）：champion + 若干偏置向量 → 测行为签名（刹车点位移、
线路统计、旋转率、圈速）。三种结局都有出路：
- 签名连贯且随偏置单调 → 假设成立，按原设计走；
- 反馈冲刷（签名微弱）→ 后备 A：**指令层人格**（档位/预算使用
  风格——档位现已被强制执行，这层差异是**已被证明**的真实行为
  差异）；后备 B：**人格微调炉**——GPU 时代每人格 25k 步微调
  （带风格奖励），20 人格一晚租金可承受。代价是放弃"人格是数据
  不过期"，每次代际班车 ×20 重烤——GPU 定价下已可接受；
- 离流形怪行为 → 偏置幅度收窄 + 训练时轻度randomize观测偏置
  （让"通道间小矛盾"进入分布）。
另两处已知但不致命：能力值→圈速差需标定台架（自动扫噪声幅度
出映射曲线）；跨赛道性格一致性未验证（同一偏置在蒙纳哥与银石
表达可能不同），列入探针实验的第二问。
**同校痕迹**问题维持原判：短期可接受，长期靠联赛分化。

## 四、攻防：风险最高的核心，也是最该插队的

诚实排序：这游戏没有攻防就是"计时赛经理"。而攻防恰是**最未被
验证**的系统——当前一切都是 solo，对手 96 通道全程为零（车手
对手盲）。已有资产比恐惧中多：1v1 环境+scripted陪练（opponentPace
拨盘）、车车接触物理、追尾责任判定、尾流物理、观测协议 6 车席位。
未验证的：对手通道点亮后的训练稳定性、自博弈动力学（互相钻空子、
brake-check 类退化）、挤压裁判、接触栈回写化石。
**裁决：1v1 概念验证插队**——champion 热启动、对手通道点亮、
scripted 陪练从慢到快、无裁判只有既有接触罚。它回答"这套架构
能不能学会有别人存在"，比再快 0.5 秒的去风险价值大一个量级。
这是 GPU 预算的第一顺位消费者。

## 五、进站：工程而非研究

程序性驾驶权笔记已覆盖（脚本域、走廊交接、unsafe release）。
真正的余量工作：赛道包维修区几何声明格式、停站时间分布模型、
比赛流程状态机。无致命未知，按配站时代班车走，不占 GPU。

## 六、训练架构与 GPU 纪律

- **母本已"够好"**：1:41-42、带内超纲、1-4 跤/百圈。冻结点在
  矩阵测量之后（若比赛档位干净即冻结毕业，飞驰零旋转降为荣誉）；
- **耐心臂（parent2i 长炉）降级为本地 CPU 免费背景任务**——
  军令状条款保留（不开案不手术），但它烧的是本来闲置的本地机，
  不占 GPU 预算，答案（磨得掉/磨不掉）什么时候到都是赠品；
- **从零原住民**：世界封版（反射层随机化落地）后在 GPU 上跑，
  产出可复述配方——内容管线的地基，成本按实测 ~8 小时/3000k；
- **实测算力账**（2026-09-14 探针）：学习器占墙钟 96%（1526 vs
  34704 tps），GPU 对现网 3-5×，对宽网 10×+；
- **GPU 纪律**：机时本身便宜（¥2+/h → 整个耐心臂≈一顿饭钱），
  真正的稀缺资源是**有方向的周**。规矩：每张 GPU 工单署名它
  去风险的系统（攻防/配方/花名册），不署名不开机。

## 七、重排后的路线图

0. （分钟级）5×5 矩阵 → 比赛档位旋转率 → 决定零旋转战役终战与否；
1. （数小时，纯评估）偏置探针 → 能力值系统的地基实证；
2. （GPU 首单）1v1 概念验证 → 攻防架构可行性；
3. （GPU）从零原住民 → 生产配方出生证明；
4. （并行免费）耐心臂本地烧，宽停自裁；
5. 之后按班车：配站时代（进站+胎标定+配方箱体）→ 联赛时代
   （裁判+风格+容量）→ 呈现时代（旗语+周末流程）。

一句话总纲：**考试为游戏让路,机时为去风险服务,每一炉署名受益人。**
