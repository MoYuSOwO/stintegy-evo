## 三、烤 AI 配方（流水线定稿要点）

1. 量基线：`frequency_sweep.py --rates 15,60`（新赛道分钟级）；
2. 烘焙：自调 α 开局 → 谷底冻结 → **best 连续 3 评不破即停、取 best**
   （预算给足，尾巴便宜且一直在付钱——275k 仍破纪录为证）；
   - **谷底冻结是 run 内自动的，不是两段式**（两段式只是这次破案的姿势）：
     检测器盯 α 历史最小值，回弹（连续数个千步窗口 α > 历史最小 × 2）即
     当场钉在历史最小值继续跑；兜底 = 步数上限（如 75k）强制冻结。
     判据全是相对量，无借来的绝对常数。
   - **接力烘焙 α 从第 0 步固定**（继承捐赠方冻结值）：接力起点是收敛
     策略，自调器开局就会加价逼抖，把接力来的功夫打散。自调只属于从零。
   - 实现：train.py 谷底检测器 + 停滞停训（下一工单）；摩纳哥 = v1 首验
     （若不及两段式,退化方案同样可自动化）。
3. 验收：干净圈 gap ≤ 阈值、干净圈率、抗命有界、哨兵探针
   （哨兵变好≠泄露警报——几何技能对同分布赛道的迁移是教义预期，
   真泄露签名是哨兵零迁移或与专家分数锁死）；
4. 不过线回退解析司机（模组安全网，规则 solo 司机因此永远要维护好）。

## 四、语义钉子（防走样，进 PLAN）

- **Push 是预算不是油门**：每档 = 冲线余量目标线（Save 15% / Push 5% /
  Attack 无线）。省在哪司机自己找（lift-and-coast 应涌现）；玩家在存量贴线时
  喊 Push 自然退化为按余量尽力跑，UI 摆投影。**逐圈只是无线电报数粒度，
  不是结算粒度**（按圈限额是被否决过的方案，勿复活）。
- 轮胎档**不**迁移目标线（现行 cap 是诚实近似；功率 cap 才是假决定）。
- 训练里切弯结构上无利可图（出界屏蔽推进 + v² 罚双重付费）；评估头条认干净圈
  后成绩单也骗不了；正赛的黑白旗/三振归赛会层（缠斗代）。

## 五、等闸门的设计（已聊透，勿提前施工）

### 动态抓地（闸门：下一次物理批次 + 代际班车）
- **世界侧用格子**：每站横向 8~12 格 × 两层（橡胶/水），**沉积量累加器**
  （车压过加质量、随时间衰减）。天然抗离群车手（单车薄胶痕质量≈0）、
  天然多峰（防守内线/雨天绕线两个鼓包免费）。
- **抓地公式**：grip = f(橡胶, 湿度)，**湿时橡胶项变号**（胶面存水）。
  雨线不是实体，是两场一交互的涌现。
- **观测侧用采样**：前瞻 18 站 × 横断面 5 点，读格子插值出的**有效抓地比例**
  （一个数，变号交互在物理里算完再给），约 +90 维，代际边缘手术接入。
  世界分辨率与观测维度彻底解耦。脚下不用喂——摩擦圆使用率/TC 通道就是体感。
- 先手项（可单独走）：**区域静态抓地**（赛道/路肩/缓冲区系数），不扩观测，
  物理定价替代白线判定的记账博弈；改完全体专家暖启动微调 + 重测基线。

### 能力值九项 → 学习司机（闸门：缠斗代；网络永远保持柏拉图司机，人格住接口）
| 能力 | 方案 | 备注 |
|---|---|---|
| Pace | 车辆极限打折（虚拟差车） | 白送 |
| TireManagement | 胎耗物理系数 | 白送（本来就是物理旋钮） |
| Reactions | 动作队列深 0~2 拍 | 时序修复时已预留 |
| Consistency | 动作噪声 + **复用规则车手 form 机器**（session/lap/段三层 AR(1)，带种子） | 便宜 |
| CarControl | 状态相关噪声：σ ∝ 摩擦圆使用率，**过 0.35s 低通**（规则栈教训：白噪声像抽搐，滤波漂移像人手）；备选方案：LimitSettleUse 式常态偏置（慢性费胎+出弯宽，无陀螺） | 巧解 |
| Awareness | 对手观测块加噪/延迟（缠斗训练随机化后分布内） | 缠斗代顺产 |
| Overtaking/Defending | **风格条件化训练**（按回合抽凶狠度进奖励权重）——同时就是"玩家下战术指令"的产品需求，能力值是副产品 | 真活但必修 |
| Adaptability | 信念扭曲不可移植（观测全真值，掺假与真值通道打架）；来世 = 动态抓地时代的**预报质量**（低能力司机拿旧而糊的前瞻抓地） | 缓期 |
- 标定纪律：**能力值同车,不标定不上船**——最低分车手的事故率按设计值（每 N 圈
  一次真失误）solo 量出来再发。噪声超出策略救援半径才会"发癫",那是可标定的悬崖;
  网络始终在闭环里做修正,车的 TC/稳定性控制垫底。

### 降阶偏航模型的极限区（闸门：下一次物理批次，与区域静态抓地同车）
- 现象（2026-09-07 3D 目击 + 遥测探针证实）：学习司机高速弯 trail-braking 时
  后轴组合饱和 → 侧滑冲到 **10° 硬限幅并钉住 ~0.2s**，再按 0.15s 时间常数
  自动回正——街机感三件套：**定角漂移（限幅）、零反打（自动回正）、白菜价**
  （唯一代价 = |a_lat·sin(β)| 刮擦，10° 约半个 g 减速零点几秒）。
- 对照：同物理下解析司机侧滑峰值仅 5.1°（150s：学习 5 次 >4°，含一次 10° 顶格；
  摆动反转 5.9/s vs 3.5/s）。专家不是发现了新物理，是**住进了解析司机从不
  踏足的极限区**，把降阶模型的软边界当地板踩。15Hz 指令阶跃极小（p95 0.7%
  满量程），**不是**主因，执行器模型不急。
- 处置：属物理批次（改定价必作废检查点，暖启动微调 + 重测基线搭同一班车）：
  滑角超阈值后侧向力衰减（真失控风险，救车能力才有意义——CarControl 能力
  设计的前置）、刮擦损失加价、硬限幅改软区。表现层不遮丑，仿真是什么样
  3D 就演什么样。
