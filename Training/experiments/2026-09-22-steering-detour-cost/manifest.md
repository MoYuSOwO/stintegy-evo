# 转向绕路费：从命令的二阶差分，改成前轮的实际绕路

parent6a 的判词是"买到了延迟，没买到治愈"（见 [2026-09-21 手册](../2026-09-21-steering-history-cost/manifest.md) 末尾）。这一腿换的是**计费信号**和**公式**，不是系数。

基线 `feat/steering-history-cost@424d928`，分支 `feat/steering-detour-cost`。观测零改动，物理零改动，课程零改动。

## 为什么二阶差分失效

旧价目表罚的是命令的二阶差分 `|Δₜ − Δₜ₋₁|`，**"匀速拉量免费"是写进设计里的特性**（旧手册第 20 行）。策略找到的出口正是这条豁免：用两三拍匀速荡出去、再两三拍匀速荡回来，每一拍的二阶差分都很小，幅度却一路长大。

实测：125k → 250k 摆幅涨 **11 倍**（0.00149 → 0.01658），账单只涨 **1.75 倍**。到 275k 摆幅 0.01881，是观感门 0.02 的 94%，与没上过罚的 5a 终局 0.01906 已无实质差别。

## 换成什么

**计费信号：命令 → 前轮实际转角。** 两者是不同的东西：齿条有速率上限，一个甩到底的命令到达前轮是一段斜坡，而策略从来不被告知齿条做了什么。读法是在 `_simulation.Step` 前后各读一次 `_ego.State.SteerAngleRadians`——围的是物理步，不是 `CommitAction`。

**主刀：两拍窗口的绕路费。** 相邻两拍的转角增量 Δ₁、Δ₂（弧度）：

    detour = (|Δ₁| + |Δ₂|) − |Δ₁ + Δ₂|

走过的路减去两端之间的直线距离。同号恒为 0（**不论快慢**），异号时等于 `2·min(|Δ₁|,|Δ₂|)`。**按滑动窗口逐拍计费**：每一拍都和它前一拍结账。

这一条就是二阶差分那个豁免的正面修补：绕路不在乎它是被慢慢绕出来的还是快快绕出来的。

**副刀：行程税 `|Δ|`，逐拍。** 绕路费的窗口只有两拍，比两拍更慢的摆动仍能溜——一个方向走三拍再回头走三拍，任何相邻两拍都不反向。行程税没有时间尺度，它是那条的地板，不是第二意见。

**单位陷阱（本腿最容易错的地方）：两个量都是位移（弧度），不是速率，所以不乘 `AgentStepSeconds`。** 家规"按每秒计价再乘步长"管的是速率项；每拍累积的弧度自己带着时间。

## 系数

| 项 | 量 | 系数 |
|---|---|---|
| 绕路费（主刀） | 滑动两拍 detour | **0.1183 /弧度** |
| 行程税（副刀） | 逐拍 \|Δ\| | **0.0182 /弧度** |

定法：让干净棒合计付进度奖励的 1.0%，其中绕路费 0.8% + 行程税 0.2%。

## 回放验证：这次真的抓到了东西

**这是回放验证第一次拦下真问题，值得留档。**

第一版系数（0.02915 / 0.004537）是隔壁离线标的。上炉前按预注册流程跑了一次回放——把系数灌进宿主，用三个参照棒实跑，看宿主**实际**收到多少。结果三条全 MISS：

| | 目标 | 第一版实收 |
|---|---|---|
| 抖舵棒 | 14.3% | 3.46% |
| 6a 终局 | 5.4% | 1.32% |
| 干净棒 | 1.0% | 0.25% |

**6a 终局 1.32% 对比旧价目表的 1.2%——几乎没变。** 按第一版上炉，这一腿存在的理由本身就落空了，而且会以"烧完三小时后发现没效果"的形式发现。

逐项对照定位（都换算成每车道秒）：

| | detour host/fit | travel host/fit | progress host/fit |
|---|---|---|---|
| 抖舵棒 | 1.1451 / 1.1438 = **1.001** | 0.7680 / 0.7677 = **1.000** | 1.0657 / 0.2569 = 4.148 |
| 6a 终局 | 0.3420 / 0.3470 = 0.985 | 0.3762 / 0.3758 = 1.001 | 0.8814 / 0.2175 = 4.053 |
| 干净棒 | 0.0726 / 0.0732 = 0.992 | 0.1178 / 0.1175 = 1.002 | 1.0732 / 0.2666 = 4.025 |

**转向两个量逐条对得上（0.1%–1.5%）**——滑动窗口实现、"滑动 = 非重叠的两倍"（实测 1.1451/0.57192 = 2.002）、不乘 `AgentStepSeconds`，三样全部验证正确。**错的只有分母。**

病因：离线探针把 `components` 的轴取反了。缓冲区 reshape 成 `(分量, 车道)`，探针写的是 `components[:, OWN_PROGRESS]`，取到的是**车道 0 的一整列十四个分量之和**，即"车道 0 的总奖励"，不是"各车道的 own_progress"。

**曾经有过一个听起来更顺的错误解释，被数据否掉了**：我先提出"多除了一次车道数"（batch=4）。但三个比值不是常数，是 4.025 / 4.053 / 4.148，而且**单调跟着罚款负担走**——抖舵棒罚最多所以比值最大。车道数理论预测三个都该是精确的 4.000。取反轴那个解释正好预测这个漂移，因为总奖励 = 进度 − 罚款。

修法不是缩放。三个 progress 直测值一拿到，系数就直接重算，**没有引入任何缩放因子**：乘 4 会把探针 bug 的残留（那个约 0.97 的罚款折扣）烤进系数里。

第二版回放，三条全中：

| | 目标 | 实收 | 绕路费 | 行程税 |
|---|---|---|---|---|
| 抖舵棒 `evalparent5c-500000` | 14.0% | **14.02%** | 12.71% | 1.31% |
| 6a 终局 `evalparent6a-275000` | 5.4% | **5.37%** | 4.59% | 0.78% |
| 干净棒 `evalparent5a-75000` | 1.0% | **1.00%** | 0.80% | 0.20% |

口径：银石、4 车道、180 秒、评估档位、确定性策略。脚本 `Training/python/steering_cost_replay.py`。

## 三条判据

① **抖舵形态持续付费**：14.02%。
② **正常过弯整圈**：1.00%。
③ **单次救车**：最贵一拍 −0.01779，对两秒被遮蔽的进度（2 × 1.0657 = 2.131）是 **0.83%**，在 1% 以内。

**② 是有意从旧目标的 < 0.3% 放宽到 1.0% 的。** 理由：实测发现卡住这件事的不是公式形状，而是我们自己定的干净预算。在 0.3% 预算下，**所有**候选公式对 6a 终局都只能收到 1.2–1.7%，彼此差别很小；预算放到 1.0% 之后绕路费才能对 6a 收到 5.4%。0.3% 当初是为了兑现"不能让正常过弯都困难"，而 1.0% 的进度奖励对过弯依然是极小的负担——判据③在新预算下仍只付 0.83%，救车那条护住了。

## 形状由六条测试钉着

- **匀速拉量免费**：单调运动绕路费恒为 0，不论多快。
- **直线稳态几乎免费**：两项都 < 5e-4（齿条满速率一拍是 0.0698，差三个数量级）。
- **锯齿每拍付费**：12 拍里至少 9 拍被计费，且匀速拉量恒为 0。
- **慢蛇行溜过绕路费、被行程税接住**：四拍一转向，绕路费付得少，行程税照付。这条把主刀的已知射程写成测试，而不是写在注释里。
- **单次救车只付一拍**：反打那一拍付，之后按同向保持的拍数全免。
- **双系数为零即零**。
- **计费读齿条不读契约**：增量制与绝对制在同一段方向盘运动下逐位同价——这条现在天然成立（计费根本不碰 action），所以断言的是"它不知道契约是什么"。

**一条没有写进去的断言：「弯中稳舵免费」。** 旧手册里有，实测做不到，而且不是实现问题：转向目标不是 `命令 × 最大转角`，它含滑角补偿项和曲率反馈项（`CarPhysics.cs` 的 `SteerTowardCurvature`），所以握住一个恒定的归一化曲率命令过弯时齿条一直在动——物理上本来就该这样，保持一条线就是要持续修转角。绕路费在那段仍为 0（动作单调），行程税不是 0。写成"免费"是假断言，删掉了，换成上面那两句真话。

## 归属：改正一处超标

旧代码注释写"Sophy charges the same thing (acted_steering_history_cost)"。**这句超标了**：Sophy（arXiv 2511.02094 附录 F）只公布了名字，没有公式也没有系数；而旧实现做的是命令流 + 逐拍二阶差分，名字里的 `acted`（实现层）和 `history`（一段窗口）两样都不是。

现在的说法统一成：**形状由名字推测，非照搬；系数全部是我们自己标的。** 本腿的实现反而比旧的更贴近那个名字（读的确实是 acted，窗口确实是 history），但这不改变"我们不知道人家的公式"这个事实。

## 探索健康：这次能测了

上一腿预注册了"σ/熵轨迹要与基线同形"，但训练日志根本不打印这两个数，**这条检查当时无法执行**。现在训练日志每行带 `H`（策略熵）和 `σ`（转向通道的标准差）。

σ 取**转向通道**而不是全通道均值：这两条罚咬的就是转向通道上的探索噪声，两个通道平均会让一个通道的塌缩藏在另一个后面。
