# D 对照 · 接力 vs 从零，两炉都没毕业

两条臂只差一个 α 口径：臂A 从 `slip-final-525k` 接力、α 从第 0 步固定
0.002；臂B 从零、自调 α 自己找谷底再冻结。物理、超参、奖励、观测全同。

## 一、结论先写

**两炉都不毕业，栽在同一件事上，而那件事不在赛车技术里。**

| | 臂A 接力 | 臂B 从零 |
|---|---|---|
| 本炉步数 | 200k（525k→725k） | **200k（0→200k）** |
| 停法 | 停训判据 | 停训判据 |
| α | 固定 0.002（继承） | **谷底 0.0014，反弹检测触底** |
| best 在 | 650k（本炉第 5 评） | 100k（本炉第 4 评） |
| **认证** | | |
| 圈数 | 55 | 54 |
| 干净率 | **78.2%** | 59.3% |
| 旋转 | 34（≈1/2 圈） | **21（≈1/3 圈）** |
| 退赛 | **0** | 3（≈1/18 圈） |
| 最快干净圈 | **1:40.973**（超带） | 1:43.776（落带） |
| 干净圈均速 | **1:42.506** | 1:46.273 |
| 出界总计 | 54.3 s | **27.5 s** |
| 毕业 | ❌ 旋转 34 | ❌ 旋转 21 / 退赛 3 |

**臂A 快、臂B 稳。** 臂A 的干净率和配速都明显更好；臂B 的旋转更少、出界
总量只有一半，但它会陷在草上（3 次退赛）而臂A 一次没有。

**从零的性价比是这份对照真正的发现**：臂B 用 **10 万步**（从空白）就到了
零旋转 + 干净过半 + 落带的评估形态。臂A 那份 best 的血统是
`bestalpha002`（旧物理）→ 滑移角暖启 52.5 万步 → 接力 20 万步。同一条
赛道、同一套物理，从零到可用的成本远低于这条血统的总长。

## 二、两炉栽在同一处，这是本单最硬的一条证据

    臂A  34 次旋转  最早 461 s  中位 535 s   400-500s:5   500-600s:29
    臂B  24 次事故  最早 341 s  中位 539 s   300-400s:1  400-500s:7  500-600:16

| | 时长 | 越过 400 s |
|---|---|---|
| 训练回合 | **240 s** | 从不 |
| 评估会话 | 400 s | 从不 |
| 大样本认证 | 600 s | 是 |

**两条独立血统的司机，在同一段时间窗里同时垮掉。** 臂A 是接力来的、
臂B 是从零长的，它们不共享权重、不共享 α，共享的只有训练协议：每 240 秒
重开一次。策略见过的最旧的胎就是 240 秒的胎，认证要它连开 600 秒。

一条血统这么表现可以叫巧合，两条独立血统同样表现，就是**协议在说话**。

## 三、落点与触发状态

**臂A**：三个弯 T3(11) / T10(8) / T14(15)，直道零。四轮表面：柏油 18、
含草或路肩 16。

**臂B**：几乎全在一个区域（20/21），一次在中段。四轮表面：**旋转 21 次
全在柏油上，3 次退赛全在草上**——它不是被路面弄倒的，是自己开倒的。

臂B 的触发瞬间读数很直白：

    时速 189  侧滑 60°  曲率峰 0.96  刹车峰 1.00

**同一秒里要了 100% 的刹车和 96% 的转向。** 摩擦圆里没有这个点。臂A 的
触发指令要温和得多（曲率峰 0.15~0.89，刹车峰 0.48~0.94），它更多是被
旧胎拖倒的；臂B 是被自己的指令拖倒的。这两种是不同的病。

## 四、给母本决策的口径

工单预写的结案逻辑是"臂B 不劣于臂A → 从零那一炉成母本"。**按认证读，
臂B 劣于臂A**（干净率 59% vs 78%、配速慢 3.8 秒、还多了 3 次退赛）。

但这个比较有一处不对等，必须写明：**臂A 的 best 是它本炉第 5 次评估
（650k）、臂B 的 best 是它本炉第 4 次评估（100k）**，而臂A 身后还站着
52.5 万步的暖启动。若按"从零总步数"记账，臂B 花了 20 万步、臂A 那条血统
花了 72.5 万步。

**所以这份对照不足以下母本判决**，缺的是"臂B 再跑同等步数会到哪"。
按纪律不加训（一炉一结论），此处只记账。

## 五、两炉共同的下一个问题

不是"谁当母本"，是**评估窗口和训练回合都短于认证窗口**。在这条修好之前：

- 评估里的"零旋转"是 400 秒窗口内的零，不能读成能力；
- 任何按评估选出来的 best，都是按一段它没被考过的路选的；
- 两条臂的对照本身也只覆盖了这段窗口。

三个选项在 `verdict-armA_zh.md` 第四节，本单不预选。
