# 极限区真实化 · 换心不换车

侧向力生成从「请求即交付」换成滑移角物理。纵向链、轮胎热/磨、空气动力、
能量、赛道几何一律不动。解析司机本单退役为仪表。

分支 `feature/slip-angle-physics`（+ `feature/slip-angle-tests`）。

## 一、装了什么

**轮胎侧向曲线**（`Core/Cars/TireSlipCurve.cs`）

    f(α) = sin(C · atan(B · α))

只报两个数，另外两个反解出来——这个方向是对的：

| 量 | 值 | 来源 |
|---|---|---|
| 峰值滑移角 | 8° | 赛用光头胎口径（初值） |
| 远端残余 | 峰值的 0.7 | 滑得动但永远比不滑慢（初值） |
| 形状 C | 1.506 | 由残余反解 |
| 刚度 B | 12.32 /rad | 由峰值反解 |

峰值归一到 1，所以**整车侧向包络没有移动**——这是所有历史圈速仍可比的前提。

**单轨动力学**（替换 `CarPhysics` 侧向/偏航段）

- α_f = δ − β − l_f·r/v；α_r = −β + l_r·r/v
- 轴侧向力 = 摩擦圆余量 × f(α)；纵向优先占圆（锁死的轮胎不转向，ABS 的意义
  由此而来）
- 偏航加速度 = (l_f·F_yf − l_r·F_yr)/I_z；β、r 正常积分
- **拆掉**：10° 侧滑限幅、自动回正公式、偏航加速度限幅、侧向的越限效率曲线
- 低速沿用既有运动学混合；侧向对按实际刚度自适应 1~4 子步

**前后平衡**：`FrontPeakSlipAngleRatio = 1.35`（前轴峰值滑移角是后轴的 1.35 倍
＝前软）。这不是装饰:**中性车（=1）一旦被多要一点就直接转，纸面更快、实际
不能开**。前软让车先推头,偏航率跟着掉,后轴滑移角随之回落,滑动自己熄火。

**转向执行器**：δ 成为状态。运动学前馈 + **滑移角补偿前馈** + 小增益曲率误差
反馈（0.5），速率上限 1.047 rad/s（方向盘 600°/s 过 10:1 齿条），锁点 0.8 rad。

> **与图纸的偏离（一处，重要）**：图纸写「运动学前馈 + 小增益反馈」。纯运动学
> 前馈的稳态误差是 **36%**——60 m/s 下要 0.004 的曲率只到 0.00293。那等于
> 「司机动作语义不变」这条自己被推翻了，而且整包络掉到 3.36g。补上滑移角
> 补偿后：包络回到 3.47g、跟踪误差 **0%**、解析栈还能用。真司机就是这么打
> 方向盘的（车推头就多打一点），所以这是把前馈做对，不是加聪明。

**深度打滑**：|β| > 35° 持续 0.25s → 旋转事件，征用封存分支的脚本化编排与
训练侧屏蔽接线（协议 v3 每步每车道一字节旋转数）。

**表现层**：`FormulaCarView3D` 直接渲染 δ。反打不再是加上去的效果，是状态。

## 四、退役的代价（如实记档）

解析司机在新物理下的生存情况。200 秒静止起步，200 秒内跑了几圈 / 贴墙帧占比：

| 赛道 | 修正前 | 修正后 |
|---|---|---|
| simple-right | 3.90 圈 / 0.6% | 4.04 / 0.0% |
| 银石 | 0.66 / **49.4%** | **1.30 / 0.1%** |
| 上海 | 0.97 / 30.3% | **1.44 / 0.0%** |
| 摩纳哥 | 0.07 / **94.0%** | **1.99 / 0.4%** |
| banked-sweeper | 2.57 / 0.0% | 2.55 / 0.0% |
| zandvoort | 3.19 / 0.4% | 1.10 / **32.3%**（变差） |
| baku | −0.06 / 74.8% | 0.51 / 55.6% |
| spa | 0.60 / 53.8% | 0.26 / 79.6% |
| monza | 0.00 / 90.7% | 0.63 / 59.2% |
| interlagos | 0.33 / 82.5% | 0.33 / 82.8% |

「修正」= **车不再宣传一个自己守不住的过弯极限**。旧模型能把摩擦圆花光，
所以 `EstimateLateralAccelerationLimit` 报整圆是准的；新模型贴不住峰，同一个
数就高了一成，任何按它规划弯速的东西**每个弯心都多要一成、就多冲一成**。
按转盘实测把它乘 0.9（`TireSlipCurve.SustainablePeakShare`）。

这不是「为解析司机调参」——它改的是车对自己极限的自述，学习司机读同一个
估计器（只读驱动上限，未受影响）。修正后银石/上海/摩纳哥从趴窝变成能跑。

**仍开不了的四条**（baku / spa / monza / interlagos）记为退役伤亡，不追。
`FamousCircuitTests` 相应改为只钉几何——那本来就是这四条赛道进集合的理由。
