# 银石起步分布对照

目的：检验从同一策略继续训练时，固定名义起步是否比当前随机起步更容易改善名义条件圈速，同时保留稳定性。此轮不是重新校准车辆物理，也不能用一次短程试验判断 RL 路线成败。

## 固定条件

- 起点：bestparent.pt，550000 步；SHA256 见 manifest.json。
- 两组均续 25000 环境步、64 lanes（各 160 万 transition），每步 2 次更新。
- 同一 seed=1；都恢复检查点权重、优化器和 RNG；都没有旧 replay，均使用原代码的 replay 预填充门槛。
- 单车、银石、240 秒训练回合；训练档位保持现有按种子抽取方式。
- 同一现有 Release 主机的独立副本，温度诊断开关关闭；训练 CPU 4 线程、评估 1 线程，两组顺序运行。
- alpha 均显式固定为检查点 log_alpha 的指数：0.0018570494139567018。原运行冻结 alpha 的标志和精确冻结值未序列化；日志显示约 0.0017，因此这是两组共享的明确控制条件，不能声称完整恢复了原运行的所有算法状态。
- 仅实验 Python 副本修正 EGO_SPEED=260、道路块=219，并将续训 TPS 分子改为本次新增步数。diagnostic-readers.patch 保存完整改动。

## 两组差异

1. nominal：--fixed-episode-start，名义新胎、90°C、80% 电量、抓地 1、气温 25°C、地温 35°C。
2. randomized：原有随机起步分布，磨损、胎温、电量、抓地和天气均按现有配方抽取。

因此本试验检验整个起步条件分布，不能进一步把差异单独归于抓地随机化或胎温随机化。

## 评估

启动前用修正索引后的评估函数验证原模型基线：最快 110.012 s、平均干净圈 110.837 s、16/25 干净、0 spins。

每组新增 12500 和 25000 步处使用原报告流程评估，包括银石和原有哨兵赛道。银石固定为 6 lanes × 600 秒、seed 900001、档位 3/3、确定性策略、名义起步。禁用早停，确保相同训练预算。

两组最终固定预算检查点 eval-575000.pt 另输出 evaluation.json；比较最终检查点，避免分别挑选最有利的一次结果。优先共同看平均干净圈、spins、退赛和干净圈比例；最快圈只作辅助。25k 只提供早期方向性证据，单一种子无法支撑总体优劣结论。

线程预检：首次单线程名义组在不足 1500 步时主动停止，日志保留在 thread-preflight，未保存学习结果供正式实验继承。短线程基准见 thread_benchmark_idle.json；选择 4 线程后，两组正式实验均从原始 550k 检查点重新开始。

## 文件

- status.json：当前阶段、任务 PID、命令。
- supervisor.log：运行阶段和异常。
- nominal/training.log、randomized/training.log：训练日志。
- 两组 checkpoints/：独立保存，不覆盖原模型。
- baseline.json、两组 evaluation.json、最终 comparison.json：评估结果。
- check_layout.py：Python 读数与 C# 布局检查。

主仓生产文件哈希在结束时再次核对。目录属于 .gitignore 已忽略的 .tmp，仅保存本次实验。
