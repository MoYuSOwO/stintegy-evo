# 学习司机训练计划

本计划是"学习司机"时代的工作地图：让一个学习出来的策略直接驾驶参与完整物理仿真的赛车，
替代分层规则栈中的驾驶决策部分。计划的每一条都来自一个明确的设计裁决，裁决理由随条目记录，
以便后来者（包括未来的我们）知道哪些是原则、哪些只是当时的权衡。

> **状态（2026-08-31）**：多赛道联训时代（v5）在总 **1M 步**处收官并做出判决：十条赛道
> 联训的天花板是训练集平均 **+11 秒**（最后 550k 步 22 次评估全程横盘），保留集在
> +21～+76 秒间振荡不收敛，两条椭圆技能单调流失；同时单赛道专家的存在证明成立
> （simple 双向**跑赢**解析，Daytona 联训中途摸到 −0.23s）。据此**方针转向：枚举赛道、
> 泛化车参数、代际处理动力结构**（见零）。车辆层完成动力总成接口重构（PR #38，见六）。
> 能量/轮胎策略台的预算式改造已定稿、施工待闸门（见七）。v5 完整判决见八。

## 零、方针：枚举赛道 × 泛化车参数 × 代际处理结构

通用跨赛道策略的路线在 v5 判决后废止。调研结论（留档）：规则式的通用缠斗无公开成功
案例（IAC 半脚本按场地调、ETH 博弈 MPC 按赛道建模、商业游戏特调+简化物理）；神经方案
单轴各有存在证明（赛道内插=我们的 simple 负间隙、车型=GT Sophy 2.0 的 340 辆），但
**没有任何人交付过轴的叉乘**。产品因此按轴分治：

| 轴 | 处理 | 依据 |
|---|---|---|
| **赛道** | **枚举**——每赛道一个检查点，模组自带；编辑器"烤 AI"按钮（零样本地板 → 固定配方烘焙 → 自动验收不过即回退） | v5 判决：联训分食容量、重心迁移挤掉无锚技能；专家证据成立 |
| **车参数**（质量/功率/容量/抓地力…） | **泛化**——训练时域随机化 + 观测描述子；新车模组**零训练**，条件是参数落在发行包络内 | 唯一有存在证明的轴（Sophy 2.0，340 辆同动作空间的车） |
| **动力结构**（纯电/纯油/混动） | **代际**——新结构=一次全体赛道检查点刷新：观测扩容 + 网络边缘手术（输入列按偏移映射置换、新通道零初始化，行为逐位恒等）+ 混合车池微调。刷新后仍是一网开全车 | 跨动作空间零样本无存在证明，永不指望（红线） |

**动作空间是策略的 ABI（总不变量）**：车与车的差异只准住进观测描述子和 `IPowertrain`
接口，**永远不准住进动作空间**。动作空间只允许在"对所有车都有意义"的前提下增长
（例：缠斗代的部署按钮——通用的"现在全力！"，每种动力总成自己兑现），且只在代际边界增长。
这是"一网开全车"的技术前提：检查点是庄稼，管线是农田；代际刷新重种庄稼（机械劳动，
GPU 小时），接口的缝保住农田（智力劳动，不可再生）。

## 一、接口：端到端物理控制

**动作空间（2 维，决策 10 Hz）**：`DriverInput` 的前两个字段——期望曲率与期望轴加速度。
本仿真的控制接口天然理想化：曲率指哪打哪、加速度近似线性，因此"端到端"在这里
不需要学习方向盘与踏板的物理，只需要学习驾驶决策本身。

- 曲率：策略输出 [-1,1]，按车辆 `MaxCurvatureRequest` 线性缩放；
- 加速度：策略输出 [-1,1]，负半轴按最大制动、正半轴按当前驱动上限缩放；
- 除物理执行器上限外**不设任何行为钳制**——没有跟车距离、没有让行剧本、没有过渡曲线。

**基线作参考，不作底座**：解析规划器继续作为测量仪与（将来的）陪练，但不在学习司机的
执行路径上。不采用残差方案的原因：缠斗中基线会坚持赛车线，残差策略必须持续对抗基线
才能保持非常规线路，这种对抗本身是学习负担。

## 二、安全：车的物理 + 赛会判罚，没有防撞层

裁决过程记录（重要，防止将来有人"好心"把层加回来）：

1. 碰撞兜底存在逻辑死结：调得早必然误伤故意的贴身驾驶（有用程度=冤枉好人的程度），
   调得准则物理上已不可避免（精准=无用）；且对手可以武器化你的兜底。
2. 真实赛车运动是"零防撞层"运行了一百年的存在性证明：ABS/TC 管的是自体物理，
   避撞是车手技能，事后归赛会管辖。
3. 因此运行时只保留两类东西：
   - **车的自体物理**：稳定性控制、牵引力控制（属于"车"）；
   - **赛会**：损人行为（责任接触、挤人出赛道）以判罚进入训练奖励，将来进入比赛规则。
4. "零接触"退役为脚本司机时代的验收标准；学习司机时代的标准是
   **责任事故率与真人水平相当**。接触有代价、有裁决、有概率，不再是系统保证。

**自费的极限不惩罚**：抓地极限、轮胎消耗等代价由物理与圈速自然定价，触发即最优的
场合到处都是，不设人工惩罚。**损人的判罚才惩罚**：责任接触、挤压，由赛会（训练奖励）裁定。

**模式合规（现行上限语义）**：动力档在物理层硬限（`IPowertrain.DriveAccelerationLimit`
按档位功率图卡驱动加速度，等同真实 ECU）；轮胎档物理层完全不限制——判罚口径取
**摩擦圆使用率超出模式允许值**的部分，配额问的是**装在车上的轮胎配方**
（`TireConfig.GetAccelerationUsage`），裁判与司机观测同源。使用率在整圆处截断（对应
"自费的极限不惩罚"）。抗命整回合约扣 8 分而抗命只多赚约 0.5 分，听话清晰占优。
**每回合随机抽取 ego 的轮胎/动力档**，否则策略只会见到 Attack。
——现行上限语义是过渡态：动力档的五个功率上限**不构成真决定**（标定注释自己承认
Attack 全程优 26 秒、五档耗电差不到 3%），预算式换芯的设计与闸门见七。

## 三、观测：452 维，track-agnostic

**铁律一（防泄露）**：同一物理局面出现在任何赛道，观测必须逐位相同。禁止绝对 s、
全局坐标、赛道长度、圈数、赛道身份。验收：多赛道训练、留出赛道评估。
（枚举方针下这条**仍然保留**：专家网络不靠身份作弊，才能被暖启动接力、被参数随机化
复用，也才守得住"泛化车参数"那半张牌。）

**铁律二**：路面以**几何**给出，不以提取量给出。曲率标量是一次有损压缩，压缩者没想到
的东西会被静默丢掉——坡度、倾角、路拱、缓冲区、左右不对称，就是这么在一台刚拿到
2.5D 世界的车上全部消失的。

**铁律三**：凡属于车而非路的量，一律给**无量纲的比例**；但**尺度量**（包络多大）给
绝对值按世界常数归一——状态量比例 + 尺度量绝对，一对才完整。这一对同时就是网络的
归一化器：所有通道出厂即 O(1)，不用统计归一（统计归一会让回放池腐烂、让保留集被
训练分布的统计污染）。

**铁律四（本轮补上）**："**缺席**"和"**零**"永远不许共用同一个编码。缺席要写在
**静态量**上（容量=0），不写在会波动到零的**读数**上（余量=0 是混动电池的日常状态）。
已知欠账：对手块的缺席编码（solo 时代全零无害，缠斗代启用 8 槽前必须审计）。

### 三之一、三个点为什么等于整条断面

路面横断面是 `z(d) = z0 + BankSlope·d + BankCurvature·d²`——三个系数。左中右三个已知
横向偏移上的高度**唯一确定**它：

```
BankSlope     = (z左 − z右) / (2·halfWidth)
BankCurvature = (z左 + z右 − 2·z0) / (2·halfWidth²)
```

所以给点不是给断面的采样，是给断面的全部。`DirectDriveRaceDriverTests` 把这条反解
钉到小数点后四位。

### 三之二、视界按秒不按米

前瞻站点跨度 = `max(60 m, 速度 × 6 s)`。固定米数的数组两头都在浪费，且**输入分布会
随速度漂移**——同一个"下一个弯"在不同速度下落在不同通道上。按秒缩放之后每个槽位的
含义与速度无关，刹车预警距离自动跟上。这是 Sony 的做法。

### 三之三、被罚的量必须看得见

史上最贵的一个洞：`mode_excess` 罚的是 `max(前轴使用率, 后轴使用率) − allowance`，
而两个操作数策略一个都看不见。规矩：**给推不出来的，不给现成能算的。**据此刻意不给的
有——`ReferenceYawRate`（= 速度 × 指令曲率）、`OverLimit`（= 两轴使用率的 max）、
`ActualCurvature`（≈ 横摆率 ÷ 速度）、绝对抓地力（给比例，换车才通用）。

长时程信息不用 RNN：短时看帧差，前瞻看对手发布计划，行为风格看手工 EMA 特征（按需）。

### 三之四、下一代观测的预定项（攒着一次换代付清，不零碎废检查点）

观测每动一次布局就废一代检查点，所以变更打包在代际边界统一落地：

1. **资源槽对 ×2**：每储能一对（余量比例, 容量绝对值）。纯车第二槽容量恒 0（铁律四的
   缺席编码），混动照实填。油电不分家：槽一就是"主储能"，个性（会不会回充、烧了会
   不会变轻）走描述子。
2. **进度偏差通道**：当前余量 − 目标线在此赛程处的值（预算式档位的配套，见七；
   被罚的量必须看得见）。
3. **车辆描述子块**：跨车参数泛化用（质量、功率、容量、回收能力等，按世界常数归一）。
4. **对手块缺席编码审计**（缠斗代启用多对手前）。
5. **（缠斗代，动作空间）部署按钮**：+1 维通用动作，全车型同义。

## 四、网络与性能预算

- MLP：452 → 512 → 512 → 256 → 动作头，含孪生分布式 critic 约 **167 万参数**；
- 项目性能前提（README）：二十辆车同场、CPU 实时——本预算满足并留有大量余量。

**推理开销（运行时唯一要跑的部分，CPU，批 64 摊薄）**：

| 网络 | 参数 | 单车 | 20 车一次决策 | 10 Hz 下占一个核 |
|---|---|---|---|---|
| **512/512/256（当前）** | **1.67M** | **0.010 ms** | **0.19 ms** | **0.19%** |
| 1024/1024/512 | 5.71M | 0.021 ms | 0.42 ms | 0.42% |
| 2048×2（论文单圈网络） | 14.6M | 0.050 ms | 0.99 ms | 1.0% |
| 2048×4（论文比赛网络） | 39.8M | 0.12 ms | 2.4 ms | 2.4% |

**推理不是约束，训练墙上时间才是。**样本/参数比按论文口径（Sophy 2048×4 吃 16 亿
transitions = 40 样本/参数），当前网络对当前数据量已经偏大；**真正的限制是一台机器能
采多少样本，不是网络能有多大**。容量判据是 critic loss 饱和，v5 全程未饱和。

**容量对照臂（欠账）**：1024/1024/512 与 512 基线的同墙钟对照，v5 期间承诺未跑，
排入专家时代第一批实验。

**性能优化队列（"五刀"，触发条件：逐赛道量产开始且墙钟成为瓶颈）**：
NStepBatcher 向量化（纯 Python 逐 lane 循环，两平台通用）→ 回放池搬显存 → pinned
异步拷贝 → 撤 stats 同步 → CUDA Graph（launch-bound 的最大刀，CUDA 专属；MPS 可试
Inductor-Metal 融合替代）。Mac 实测每步 ~45ms（2×更新 + 环境 + 胶水）；5090 盒子
~42ms（Xeon 单核慢拖累 Python 胶水，GPU 利用率仅 8%）——**优化前租卡无意义**。

### 四之二、为什么现在不上复杂架构

**原则：复杂度用来回应已诊断出的问题，不用来预防想象中的问题。**

**LLM 的 scaling law 不能直接搬**，四条前提全不满足：RL 数据自采（加参数不产生经验）、
目标自举非静止（容量大拟合错误目标更快）、单样本信息量低几个量级（瓶颈是样本）、
任务是光滑低复杂度函数（容量够表示后再加是浪费）。2024 起 BRO/Simba/CrossQ 证明
RL 网络可以放大变好，但前提是 LayerNorm/残差/强正则——**朴素 MLP 不 scale 是"朴素"
的问题不是"大"的问题**。

**甲类（公认更优默认值，开局就抄）**：孪生 critic、自动熵调节、tanh 压缩、分位数
分布式 critic（32 分位）、critic LayerNorm——均已在用。QR-SAC 的针对性：过弯结果双峰
（过了/撞了），期望回报描述的是不存在的结果，分布式 critic 能表达"七成过三成撞"。

**乙类（任务专属，等诊断出问题再加）**：

| 观察到什么 | 才上什么 |
|---|---|
| 奖励稳定但学习卡在基线之下 | 加宽网络（先跑容量对照臂） |
| 对局阶段对手相关学习低效 / 名次交换抖动 | 集合编码器（DeepSets/注意力）——"右前方有车切过来"现在要在六个槽各学一遍，共享 φ 只学一次 |
| 需要记住对手风格 | 手工 EMA 特征 → 最后才 RNN |

**明确不采用**：model-based RL（Dreamer/TD-MPC）。卖点是用算力换样本，我们样本极便宜、
算力才是瓶颈——方向相反。

## 五、训练

- **算法**：QR-SAC——分位数分布式 critic（32 分位）、孪生 Q 取均值较低头的整条分布、
  Polyak 目标、critic 层归一化、n 步回报；timeout 与 terminal 分离
  （`episode_end` 冲 n 步队列，`terminal` 决定自举存亡；timeout 从重置前帧自举——
  没有这条时策略学出"电门封顶"，因为回合末的加速被折价为零）。
- **赛道划分（v5 定稿，17 条）**：

  | | 赛道 | 考点 |
  |---|---|---|
  | **训练（10）** | 银石、上海、赞德沃特、simple 左/右、banked-sweeper、flat-sweeper、巴库、新加坡、葡萄牙 | 坡度 −15.4%～+9.0%、倾角至 20°+、街道窄至 7.6 m、长直道、平/斜 sweeper 同布局隔离倾角变量 |
  | **保留（7）** | 雪邦（同分布）、摩纳哥（窄+坡叉乘）、Daytona（31° 倾角外推）、speedway（平椭圆极速）、斯帕（11.4% 坡外推）、蒙扎（低下压）、英特拉格斯（逆时针） | 保留集是**测量仪不是及格线**（枚举方针下更是如此） |

  解析飞驰圈基线与圈长常数见 `train.py` 的 TRACKS 表。着色规则：真实布局投影自
  bacinger 开源数据（MIT），宽度按公开资料分区指定。

- **覆盖工程方法论（v5 的核心产出之一）**：量联合分布的洞 → 造针对性赛道补洞
  （同布局隔离变量，如 banked/flat-sweeper 对）→ 保留集当测量仪。已验证的结论：
  单轴覆盖**不免费合成**（倾角×速度、窄×陡×墙都要专门喂）；**外推失败不是缺陷，
  栅栏修在编辑器上**（发行内容参数范围 ⊂ 训练范围 + 余量）；无锚定技能会被训练重心
  迁移挤掉（speedway、Daytona 两案）。
- **评估（协议 v2）**：**真冲线计时**——race distance 越过圈长整数倍触发、步内插值、
  丢首圈取最快；460 秒飞驰圈窗口；DNF 计 min(gap, 120s) 不再静默除名。曾用"平均配速
  冒充圈速"与 90 秒量不完一圈，皆为教训。
- **对手与课程**：1. 单车跑圈 ✅ → 2. 单赛道专家（当前） → 3. 缠斗代：
  **冻结检查点联赛**（对手从历代检查点池抽取，回合内静止、跨训练缓慢演进）。
  天真同步自博弈不可用（论文原话 "the straightforward application of self-play was

### 五之二、α 不能照抄：量纲教训

论文把 α 固定在 0.01，照搬训出七万步平线。原因是**奖励量纲差 50 倍**：论文进度奖励
按米（~5/步），我们 0.02/米（~0.05/步）；α=0.01 在他们那儿是回报的千分之二，在我们
这儿是百分之五十。自调 α 自己收敛到 0.001（换算回论文量纲 0.05，量级对上他们的 0.01）。

**教训（这个形状会复发）**：论文常数分两类——关于**时间视界和梯度**的（n 步、γ、
裁剪、频率）可平移；**与回报相加减**的（α、某种程度上 critic 裁剪阈值）必须按自己的
奖励量纲折算。抄数字之前先抄量纲。进网络的每个数，不管走观测的门还是奖励的门，
都得先问一句"你按什么单位计价"。

## 六、车与动力总成（2026-08-31 重构，PR #38 已入 master）

策略台的本质不是电池，是**资源 + 档位**——存量会跑掉的东西、拿存量换配速的旋钮，
这个游戏在任何动力形式上同构（引擎图×油箱、部署×电池、输出档×电池）。据此把机器
搬到接口后面，梯级和存量留在原地：

- **`IPowertrain` 五个提问**：此刻允许多少驱动加速度 / 这步花掉多少 / 刹车回收多少 /
  存量多重 / 额定输出可交付几成。只说瓦特、焦耳、公斤——加速度和抓地力是底盘的词，
  质量与力上限是**传给**它的。`ElectricPowertrain` 是原车整体搬家，数字零改动。
- **质量每步现问**（`TotalMassKg` = 底盘 + 存量余重）：烧油变轻在载荷转移、抓地估计、
  横摆响应全链路自动生效。轮胎做功参考载荷**故意**留在固定底盘质量上——参考跟着油量
  掉会抵消它要显示的效应。
- **`PowertrainState` 两格资源槽**；**`ModeLadder` 任意级数**（≥2），策略存档位序号，
  跨车越界夹到顶（存档寿命比车长，换车能加载不拒载）；**`CarDashboard`** 仪表全由车报
  （存量名、档名、级数、输出可用度），HUD 无一字硬编码。
- **验收**：四条黄金轨迹逐位一致（力上限/功率上限/回收/垂降/空电各分支）；双储能假
  油车证缝是真的（满空油四轮载荷差 = 100kg×(g+下压)）；七图/三图引擎证五档无处硬编码。
- **纪律**：不发未标定的车。油车/混动的功率曲线与消耗必须像电车当年一样对着真实圈速
  标定后才上船。
- **混动预案（三层分工，代际落地）**：车队墙 SOC 目标线管**有限性** / 司机部署按钮管
  **时机**（缠斗代，通用动作） / 动力总成映射表只管**反射**（刹车回收、松踏板断流）。
  混动第一代不动动作空间（混合比走映射表，现实 F1 同款——车手手上本来只有超车按钮），
  落回参数泛化疆域。**反射可以自动化，时机永远交给看得见局面的那一层。**

## 七、能量与轮胎的策略台：从上限到目标（设计定稿，施工待闸门）

**为什么改**：限总功率不是任何人省能量的方式。一圈能量大头在推开空气（功率 ∝ v³），
压功率上限只在本就功率受限的路段起效，得到接近线性的交换——线性交换有唯一最优解，
"永远开 Attack"不是决定。真实省能是**行为**：刹车区前提前松电门（放弃的动能下一秒
本要扔进刹车，回收帽只吃得下峰值刹车功率的 ~11%，其余变热——小时间代价换大能量节省，
凸交换才有决策）。轮胎同理：真实省胎是挑弯省、避免滑动，均匀比例是可用的一阶近似
（磨损大致随全场使用率累积），动力的均匀上限则是糟糕的近似——所以轮胎档"还好"而
动力档"突兀"，有物理原因。

**原则：策略台下达目标，司机改变行为，车只保留物理。**本游戏本来就是车队墙游戏——
玩家从不踩油门，策略台上每个旋钮都该是对司机的指令；功率上限是唯一绕过司机伸进电机
的旋钮，这是它突兀的结构性原因。

**语义（换芯后）**：每档 = 一条按赛程距离连续插值的**余量目标线**。

```
Save   冲线剩 15%（攒储备）      Push    冲线剩 5%（吃进垂降区一点）
Eco    冲线剩 10%               Attack  不管进度表
Normal 冲线剩 ~9%（压着垂降线到家——现有标定语义的直接翻译）
轮胎同构：磨损进度线（迁移排后，现行 cap 是诚实工作着的近似，不急）
```

**奖励粒度——按圈太稀疏（一圈 ≈ 800–1100 步），解法是势函数塑形**：

1. 目标线按赛程距离连续插值，**每步**可读偏差——稠密的原料有了；
2. 但直接每步罚偏差会罚掉健康的块状省法（最优省法本来就该两条长直道狠省、其他不省）；
3. 所以用 **potential-based shaping**：`φ(s) = −λ·max(0, 目标(s) − 余量)`，每步加
   `γ·φ(s′) − φ(s)`。望远镜求和 ≈ **终点欠账**——数学上等价于只在冲线结算的预算罚
   （最优策略不被路径形状扭曲），但梯度信号每一步都有：这步透支了立刻挨罚，之后追回
   立刻退款（γ=0.9896@10Hz 的折扣失真可忽略）。这是"积分约束稀疏奖励"的教科书解法。
4. **逐圈只是 UI**（车队墙无线电报数的粒度），不是奖励结算粒度。
5. 观测配套：进度偏差通道（三之四第 2 项；被罚的量必须看得见）。
6. **物理兜底已在**：低电量垂降的平方衰减就是超支的终极刑罚（当年按"花超毁掉比赛"
   标定），司机完全抗命也会在末段爬回家——指令的意义是避开这个结局。
7. **换档重锚**：改档时目标线从当前 (赛程, 余量) 重画到新档终点。过去的账已由塑形
   结清，不二次追讨。
8. **机器复用**：mode_excess 裁判同款管道，量的东西从"瞬时超配额"换成"势差"。
9. **省的行为不写死**：不硬编码提前多少米松电门——省在哪由策略自己找，lift-and-coast
   应当是涌现行为。这正是学习司机的全部理由；若能脚本化则不需要神经网络。
   （对论文：Sophy 未做能量管理，此处是新贡献点。）

**三道闸门（全过才施工）**：

1. **稀缺门**：现状 Normal 跑完剩 8.8%、Attack 快 26 秒只多耗 3%——能量不稀缺则
   "省到什么程度"是空指令。改容量或赛距一个数，解析司机扫描确认取舍曲线存在（时间
   损失涨得慢、能量节省涨得快才立项；接近直线则换机制，不硬做）。
2. **观测门**：偏差通道 + 资源槽对，搭下一代观测班车（一次换代付清）。
3. **司机门**：预算指令由学习司机执行；解析司机保持旧上限当笨执行（指令是接口，
   执行方式归司机——笨司机省得又慢又少是真实，也是学习司机的卖点）。

## 八、v5 时代结论（多赛道联训，总 1M 步收官）

**训练集：550k 步买到零进步。**总 450k→1M 的 22 次评估，训练平均差在 +10.3～+12.4s
横盘（起点 +11.1，终点 +11.1）。十条赛道分食一个 1.67M 参数网络的天花板就是 +11 秒。

**保留集：不收敛，振荡 +21～+76s。**分案：

- **两条椭圆单调流失**：Daytona 从 −0.23s（一度赢解析）一路 +0.7→+2.4→+4.9 后连续
  十评 DNF；speedway 同型（+34→+113→死）。无锚定技能被训练重心挤出——第二次发生，
  规律成立。
- **摩纳哥处方部分起效**：三味药（新加坡、葡萄牙、flat-sweeper）入组前从未完圈，
  入组后 22 评完圈 5 次（最好 +15.6s），完圈与 DNF 反复横跳。支撑集边缘的策略无锚，
  权重微动行为大变。
- **蒙扎**同样横跳（完圈时 +13～19s）。

**这份成绩单支持方针转向**（它的病正是枚举方针要溶解的）：联训平台期 = 容量分食；
椭圆流失 = 重心迁移；而**专家天花板的存在证明就在同一份数据里**——simple 双向赢解析
（−1.28/−1.13s），Daytona 在联训分心的条件下都摸到过 −0.23。专家网络地板 ≥ 解析，
即枚举方案的全部前提。

## 十、运维备忘

- **训练进行中禁改主树 C#**：主机与评估子进程都是 `dotnet run` 拉起，源码一改，下次
  评估（每 25k 步）触发重编、覆盖运行中的 DLL——轻则杀实验，重则评估与训练悄悄跑在
  不同物理上。改代码去克隆（`git clone --no-hardlinks`），完成后 `git fetch` 引用回主
  仓库（不碰工作区、不触发重编）。动手前 `pgrep -f train.py`。
- **长训练必须脱管**：`nohup … & disown`（会话重启会杀子进程）；zsh 别名在 nohup 后
  不展开，必须用 venv 绝对路径 `Training/.venv/bin/python3`（否则落到系统 3.9）。
- **起任务前查旧进程**：曾发生双进程共写 log 与检查点。
- **租卡**：`STINTEGY_HOST_BIN` 指向自包含发布二进制直跑；Ubuntu 22.04 的 OpenBLAS
  0.3.20 在 Sapphire Rapids 上内核误检算错数（dgesv 报良态矩阵奇异），
  `OPENBLAS_CORETYPE=HASWELL` 治愈；5090 对当前小网络无优势（更新是 launch-bound，
  GPU 利用率 ~8%），五刀优化落地前不租。
- **陈账**：`smoke_client.py` 仍说协议 v1（升级或退役；`host_env` 冒烟可替代）。
